# ContasDeViagem

Aplicativo móvel para registro de despesas de viagem e geração da
prestação de contas. Projeto da disciplina DIM0524 — Desenvolvimento
de Sistemas para Dispositivos Móveis, UFRN, 2026.2.

## Equipe

| Nome | Matrícula | Papel |
|---|---|---|
| João Mello | 20250050643 | Desenvolvimento integral (equipe de um integrante) |

**Coorte de apresentação:** B

## Ambiente

Desenvolvido em Windows. O `kdoctor` é exclusivo de macOS; a verificação
de ambiente foi feita pelas checagens do plugin de Kotlin Multiplatform
no Android Studio.

## Alvos

Android (prioritário) e desktop. Os alvos iOS estão declarados no
projeto, mas não são compiláveis no ambiente de desenvolvimento usado.
